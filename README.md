# motor
Código do sistema de restaurantes (parte que roda no navegador). **Não editar aqui**: este repositório é gerado a partir do repositório privado.
Cada restaurante usa uma pasta: `estavel/` (acompanha as atualizações) ou uma versão fixa (`v1.27/`, ...), escolhida no `config-restaurante.js` do restaurante (campo `motor`).
